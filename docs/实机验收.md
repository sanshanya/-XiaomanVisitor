# 实机验收清单

适用于当前开发构建，版本以 manifest.xml 为准。此清单是项目手册的验收附件。

普通店铺视窗专项
本版撤下高清 UI，复用原生人物渲染及遮挡。仅在小满可见时采用原生非像素相机模式，之后恢复；图片文件未修改。
1. 观察从左侧走近、站定、对话和离开：清晰度应连续，仍保留暗影渐亮，不应先模糊再跳到高清。
2. 确认衣服和下半身被柜台正常挡住，走动时也不能盖在柜台或两侧墙面之上。
3. 打开放大视窗再切回；确认人物不消失、不重影，口型与语音继续匹配。
4. 接待下一位原生顾客，确认显示与设置已恢复；之后再见小满应正常启用。
5. 在小满接待期间更改窗口/全屏及1080p、1440p、2160p设置，离场后应保留新选择，不强制改回旧设置。
6. 本整理版移除了常驻画面探针；0.0.3.3 的原生输出实测依据保留在 docs/evidence。离线检查不代替本版实际画面验收。

实验性酒馆开关
1. 首次安装或旧版升级后，选项默认为关闭。正常启用小满模组，夜间地图应没有酒馆卡片；周一来访、纸条、磁带、回礼酒和收纳物品正常。
2. 在模组设置的“实验性 / Experimental”中开启“小满的酒馆（实验性）”。设置标注需重启；本次运行保持原状态，保存退出并重新启动游戏后才出现酒馆入口。
3. 已有酒馆账本或取餐台协作记录的存档，关闭选项并重启后隐藏入口。再次开启并重启，原记录仍在；不会重复扣款、补发回礼或重新推进周一剧情。
4. 在酒馆内修改选项时，当前场景和交易继续正常，重启后才切换。中日英界面均有对应的实验性说明。

酒馆第一阶段（仅在开启实验性选项并重启后）
1. 从游戏第1天起即可在夜间选择进入酒馆；完整酒馆正式开放仍计划第3天。
2. 使用作者提供的v2室内构图，小满、背景和吧台前景独立显示。
3. 保留六种表情、三档口型和眨眼；有录音时按声音驱动口型，停顿与离场闭嘴。
4. 普通杯测试价35 CR，现场饮用，不生成库存道具，也不触发六款回礼酒的三日效果。
5. 帮忙整理取餐台后，吧台出现“取餐”牌。项目跨天和读档保留。
6. 每晚最多点一杯或做一项协作；查看账本和返回不占活动次数。
7. 账本记录实际点单、支出和整理取餐台；没有虚构NPC收入或自动结算贷款。

酒馆原生对话气泡
1. 招呼、点单和协作回应从小满身旁的原生气泡显示，姓名牌随中日英界面切换；操作面板不再显示人物台词。
2. 使用原版打字机和文字动画。调整原版对话速度、气泡大小或关闭打字机效果，下一次说话应相应变化。
3. 点击气泡或按原版继续键，第一次补全文字并停止语音，再次结束显示；不能触发当铺交易、下一位顾客或周一剧情。
4. 字幕显示完但录音仍在播放时，等待配音选项开启应保留气泡，嘴继续随声音运动。关闭配音时按原生逐字状态驱动口型。
5. 长句、窗口大小变化及高分辨率下，气泡不应跑到操作面板外，也不能被吧台挡住。
6. 返回、关闭窗口、重进酒馆及切换存档后，不残留旧气泡或语音；回到当铺后原生气泡正常。

存档接入
默认关闭时不初始化酒馆进度。开启后的新开局从第1天开放，已开始的旧存档也可访问；记录起点为首次开启当天，不追收过去的房租、贷款或经营费用。关闭开关不删除保存的酒馆记录。
已完成原有十四次离站剧情的旧存档保持离站结局，显示已歇业；本版不会让她自动回来。
酒馆消费和协作独立保存，不推进周一剧情，不触发当铺交易奖励，不改变原生顾客队列。
原生一次外出限制、封锁和次日影响仍由游戏处理。

建议实测
1. 开启实验性选项并重启，使用未完成离站剧情的存档，在第1天及以后关店，翻到“小满的酒馆”卡片，进入。
2. 检查背景全景、人物大小、吧台遮挡；分别试1080p、1440p或2160p。
3. 钱不足35 CR时，点单应不可用。余额正好35 CR时，应只扣一次并归零。
4. 点单后快速重复点击、关闭再打开界面，均不应再扣钱；本晚协作不可再做。
5. 另一个夜晚先协助，应不扣钱，出现取餐牌，并阻止本晚再点单；以后可以继续点单，不能重复完成取餐台项目。
6. 查看账本后合上，或使用原生返回按钮/窗口关闭按钮，均应正常回到当铺。
7. 回店后正常保存退出，重载存档，确认现金、账本、协作标记一致；换一个存档不应串数据。
8. 确认点单和协助的日语录音只播放一遍，音频未结束时嘴仍会动，返回后声音停止。

待后续制作
经营周账、四档客流项目、NPC订单、转租、贷款重组、留下分支、分红和物业收购不在本阶段。
新招呼使用测试字幕与打字口型；待作者定稿后录制。现有107条录音保持不变，点单与协作复用已有录音。
酒馆配音待审文件是整理材料，不应单独覆盖现有配音索引；正式录制时应合并到完整配音清单。
测试版只准备本机与开发分支，不上传工坊。

抬枪反应测试（只瞄准，暂不开火）
1. 在小满开场说到一半、等候交易、成交回应三个时点抬枪。沿用原生枪械与视窗，先受惊、再持续紧张；冷汗、蓝紫额头阴影和蓝色瞳孔清晰，不跳身形或穿出柜台。
2. 新台词仅字幕，原生打字机继续工作；嘴随出现的字符开合，省略号停顿和说完闭嘴，持续瞄准时不恢复平静脸。关闭打字机时不空嚼；关闭立绘动画时保持静态口型。
3. 左键及任何原生开火入口均不能射击小满：无枪火、伤害、尸体、追捕或存档后果；右键仍可正常收枪。其他顾客的原生持枪行为不变。
4. 收枪后显示“……吓了我一跳。”，随后续接原生暂存对话。分别测试自动推进、手动推进与跳过台词，不重复开场回调、交易或赠礼。
5. 在收枪回应尚未结束时再次抬枪，反复切换后仍能回到最初对话。等待时再次抬枪不把她直接送走。
6. 切换中日英、变更立绘大小、放大视窗、离店、读档和停用模组后，不残留惊吓状态、字符监听或额外纹理；下一位原生顾客正常。
