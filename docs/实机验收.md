# 实机验收清单

本页只记录作者需要在游戏中操作的验收路径。需求与数值以[项目手册](项目手册.md)、定稿输入和manifest为准；自动通过不自动勾选实机通过。旧阶段的逐周检查可从Git提交`879650c`查阅，不在此重复。

每轮记录：实际安装版本／游戏版本／旧档或新档／语言与分辨率／其他已启用模组／操作与结果。尤其先核对安装版本，不能用旧包评价新修复。

## 1. 原生流程与设置

- [ ] 未保存设置时酒馆默认开；已保存关闭选择不被覆盖。修改不弹警告、重启生效，关后保留旧进度；周一主线/既有收藏和酒效正常。
- [ ] 周一小满位于队尾，原生剧情人物、数量和顺序保留。感谢、材料和推荐客人也只追加；原生电话/其他地点/报纸可正常操作。
- [ ] 在小满、原生顾客、空柜台三个场景分别打开NEWS。第3–7天装修、22–24天招商、57天开业、71–73天延长；过期撤下，原生四条优先，不重复文章或更改世界事件。
- [ ] 第22–24天招商电话有“同意／下次再说”；挂断/暂缓不登记，同意后次日仅一位评估员。已有预约不因新闻到期被取消。

## 2. 十四次会面与礼物

- [ ] 正常及缺席周一都只推进实际见面的一章；当天重入/读档不重复推进。初始预算、需求和曲目符合来访安排，显示没有0或未替换占位符。
- [ ] 完全不成交、不夜访仍在实际见面次日收到纸条与磁带。柜台有空优先放柜台；满载待投，已有收藏不搬动，重载不重发。
- [ ] 第三封A/B由第三次会面当夜实际完成的有薪工作决定；早几天工作不算。第四封A/B以相应已签记录决定，不凭后来的选择改旧信。
- [ ] 第一封赠礼附一次信笺簿/磁带盒；纸条/磁带无进度编号，信笺簿为粉色，允许的收纳物正确。
- [ ] 第5次即兴酒一次；第6次随机酒精版、第12次露华及第14次三种酒精版数量正确。赠酒周不额外售酒；露华夜领和次日补投共用一份。
- [ ] 第13次后地图仍可进入收店酒馆，但不再新售酒、打工、收料/续签或抽推荐；已收材料仍交付。第14次后地点消失，次日最终赠礼仍到达；缺席不按日历提前关店。

## 3. 酒馆体验与原生背包

- [ ] 第1–2天无地点，第3–7天只有装修预览且不能扣外出，第8天夜间开放；真实外出次数与原生封锁照常。
- [ ] 原生地面/口袋/背包可开关、拖动、嵌套容器和使用物品；右下角背包/返回可用，往返不复制物品。
- [ ] 点击小满是紧凑选项气泡；选项向右避开正文/姓名，空间不足只移动选项。点外部仅收起，不穿透点中雨幕/磁带机。
- [ ] 酒单半透明，原生配给站样式，商品板与“买单”分开；名称、价格、完整Buff及持续时间可见，窗口能拖动且刷新保留位置。
- [ ] 雨幕首次发现才有介绍；磁带机用原生界面，每次只有当章一盘，可拖到播放区但不能带走，也不把玩家收藏清空/拿来播放。
- [ ] 同夜多次进入/读档不重播完整迎宾或重置当天资格；退出后没有残留热点/窗口，原生音乐、报纸及其他物件正常。

## 4. 付费、工作与回礼

- [ ] 每日现场最多一杯，买单后扣准确金额并生效，背包不生成酒；取消/余额不足不扣款、不占资格；同日重入/读档不能重复喝。
- [ ] 六款果汁版/酒精版对应三类Buff，三天含当天；异类叠加、同类替换。梦游即兴版一天；露华只给当天实际卖货收入+15%，不增加工资、赠款或顾客支出。
- [ ] 原生禁止拾荒时，拾荒酒不能解除禁用；任务声望/声望损失不加成；没有酒效时原生结果不变。
- [ ] 第8–14天递酒单独立一次，无工资/长效经营奖励；第15天后有薪工作约3秒，进度条位于人物上方，完成后仅发一次工资。
- [ ] 工作中途离场/读档不发工资，原未提交订单可重开；完成后重入不重发。喝酒和工作各自限次，不互相刷新。
- [ ] 让利、数量、金额三类普通回礼分别触发；未达标不送、同时达标也只一杯。预算不足少付不算主动让利，她卖酒和现场消费不算向她供货。
- [ ] 推荐客非周一出现、同日最多一位，重载不重抽类型/预算；感谢每周最多一次，周一合并后不新增章节、磁带或售酒。

## 5. 材料合作与容器

- [ ] 第22天后必须在酒馆明确签约；没签不自动周三上门。暂停取消未来收料，已收材料继续交付；周五回答继续才安排下周三。
- [ ] 周三原生交换表显示估值、动态上限、预计价值和已达上限提示；水不计容器价，药品/违禁品/成酒/可复用培养装置及有子物品容器不被接受。
- [ ] 单件及多件不同材料分别成交，全部按原生移出柜台，接受台词和周五记录完整，双方信用点不变；其他角色以物易物照旧。旧错误留下的不确定回执不自动补发或重扣。
- [ ] 空台、撤回、取消、全无效材料不生成周五送酒；任意正价值可收。初始上限500，每周增100至3000，暂停续签不重置。
- [ ] 250 CR材料当周五交两大瓶并留25 CR；小瓶30、大瓶150；不足一小瓶只留账，之后不重复加成。
- [ ] 首次实体瓶装酒真正放入玩家库存后才给3×3酒箱；剧情酒、购得酒或仅记小额余值不发箱。满载补投/重载不重复，箱内只收允许的小满酒。
- [ ] 在收料、交付部分酒后及续签前各保存重载；材料不重扣、整瓶不重发、余值不丢，较新暂停/续签选择不被旧回调覆盖。

## 6. 立绘、配音与停用

- [ ] 店铺走近、站定、讲话、离开清晰度连续，前景挡住身体；放大/射击视窗切回正常。酒馆眨眼、呼吸、环境光与声音口型正常。
- [ ] 小满可见时改变分辨率、全屏或像素设置，离开后保留新选择；下一位原生顾客的相机和显示恢复。
- [ ] 中文字幕、日语录音、表情和口型对应，音频未结束时仍有口型；音频停顿闭嘴。禁用配音或无录音时正常打字，不串播旧句；中日英UI/长句及颜文字完整。
- [ ] 开着/不开Station Voices分别接待小满和原生顾客；不双重发声，也不误停其他顾客声音。小满讲话期间跳过、打开其他UI和切对话，不重做成交或回调。
- [ ] 语音播放中读另一个档/新开局，旧对白结束回调不能打开交换表、结束新顾客或推进旧剧情；正常当前对白仍能完成。
- [ ] 若游戏提供即时/紧急停用，在模组访客接待、材料表、语音等待和酒馆中分别验证：只撤离自有访客/地点、取消等待，柜台原有玩家物品保留；原生顾客及原生对话不被赶走或完成。
- [ ] 小满抬枪/收枪反应正常、不能开火；其他顾客规则照旧。反复切换不覆盖原暂存对白、不额外推进章节/赠礼。

## 7. 失败与长时间运行

- [ ] 满载时等待，腾出空间后只补未完成物品；重复打开窗口/菜单不重复结算。
- [ ] 对钱款或物品身份无法确定的旧回执，只暂停相应业务并提示；不重置整个存档，不猜测扣款/发货。
- [ ] 连续多次进出酒馆、听歌、切语言与开关原生窗口，资源/声音/热点不会持续残留；记录1080p/1440p/2160p及窗口模式下的实际帧率/内存观察。

剩余的留下路线、债务经营、场景物件交互与独立酒品美术不是本轮验收的已完成功能。当前固定结局不能按未来经济稿验收。
