# 实机验收清单

适用于当前开发构建，版本以 manifest.xml 为准。此清单是项目手册的验收附件。

作者反馈的界面修复专项
1. 第8天起进入酒馆，原生“地面／口袋／背包”窗口在场景上方可见，容器可正常打开和拖动；左下角“背包”可隐藏并再次显示。往返及读档不复制物品，不多消耗外出机会。
2. 点击小满只出现三个紧凑的原生样式选择气泡，没有标题和大背景框；互动与帮助／工作确认同样使用气泡。选择不推进当前当铺顾客，不影响工资或赠礼；酒单详情及选曲仍为独立窗口。
3. 分别显示和隐藏背包、改对话气泡大小、切换中日英与窗口分辨率，选择及正文避开脸和背包，上下不漂移；离开后没有残留按钮。
4. 第二、三次采购分别显示200、250信用点，不出现花括号或0。后续各次显示固定初始预算，保留静态录音的核准文本。
5. 柜台有空时新信和磁带先出现在柜台并有原生到达提示；柜台满时才尝试信笺簿／磁带盒，提示说明已收纳。旧已收纳物品不搬动、不补发；满载和读档仍遵守原有投递回执。

原生 API 更新专项
启用时不再请求“停用后仍可后台运行”；核对自动等待配音、手动跳过及当铺离场正常。开发本地包的“非创意工坊来源”说明仍是游戏自身提示，与后台运行权限不同。

普通店铺视窗专项
本版撤下高清 UI，复用原生人物渲染及遮挡。仅在小满可见时采用原生非像素相机模式，之后恢复；图片文件未修改。
1. 观察从左侧走近、站定、对话和离开：清晰度应连续，仍保留暗影渐亮，不应先模糊再跳到高清。
2. 确认衣服和下半身被柜台正常挡住，走动时也不能盖在柜台或两侧墙面之上。
3. 打开放大视窗再切回；确认人物不消失、不重影，口型与语音继续匹配。
4. 接待下一位原生顾客，确认显示与设置已恢复；之后再见小满应正常启用。
5. 在小满接待期间更改窗口/全屏及1080p、1440p、2160p设置，离场后应保留新选择，不强制改回旧设置。
6. 本整理版移除了常驻画面探针；0.0.3.3 的原生输出实测依据保留在 docs/evidence。离线检查不代替本版实际画面验收。

第一周：来访、配音与赠礼
1. 周一小满追加队尾，原生顾客仍先接待；开场、自我介绍、发现磁带机与购物的旧录音正常。
2. 发现磁带机后依次出现“我搬家的时候，也带来了不少磁带呢”“现在还听磁带的人，已经很少了吧”。两句无新录音，打字机与字幕口型正常；随后购物录音继续，不能串播上一句。
3. 分别测试成交与不成交：均在实际见面次日收到新纸条与 Title；只在成交时播放成交台词。
4. 首封信称呼“致店长先生”，包含“两盘一模一样的磁带”和“常听的”。三语切换、手写排版、首次信笺簿与磁带盒正常，物品不显示进度编号。
5. 达成原有金额、数量或让利条件，仍可次日获得一杯回礼酒；未达标不送。信与磁带不依赖回礼酒。
6. 缺席首个周一，首次剧情保留到下个周一；礼物按实际见面次日投递。保存重载不重发，空间不足会继续等待。

第三天装修简讯与地图
1. 第1—2天不出现装修简讯或地点，包括已开启实验性酒馆选项的新档。
2. 第3—7天打开原生 NEWS，有空位时显示匿名的新店装修简讯；不要求见面、成交或读信。原生新闻满四条时全部保留，本周空出位置后再显示。
3. 重复开关报纸、读档及切换三种语言，不重复插入文章，不改变原生事件、物价、顾客或剧情进度。
4. 实验性选项默认关闭时不注册地点；开启并重启后，第3–7天显示“商业街神秘新店 / 装修中”，展示已选定的酒馆内景配图，保持装修中不可进入。
5. 地点不可进入，不消耗夜间外出机会，不创建酒馆经营记录、不改变现金；原有其他地点可正常选择。新闻是否读过不影响地图出现。
6. 第8天夜间正式开放，与白天成交及是否读信无关；旧的第1天预览设置不再有效。完成旧离站结局的存档不能自动复活角色。

第二周：开业与交互（按v4.1由作者实机验收）
自动回归对应W02-A01–A16的日历、会面、记录、恢复及素材约束；画面点击、背包和原生夜访机会须在游戏中确认。
1. 开启实验性酒馆并重启，第8天夜间进入；原生夜访扣一次机会，原生背包可使用。第1–2天没有入口，第3–7天不可进入。
2. 第二次会面买日用品、预算200，四句邀请后购物；迟到的第二次会面说“最近终于开门”，不说“今晚”。不成交仍于次日送第二封信与Intro，满载与读档不吞礼或重发。
3. 已相识玩家首次迎宾三句只完整播一次；未相识时先自我介绍、不称前辈。同夜第二次与第三次、翌日迎宾符合稿件，读档保留计数。
4. 点击小满出现酒单／互动／只是看看；菜单问候与按钮同时出现。互动内只有闲聊、可用的开业接待和返回，不出现旧普通杯、账本或取餐台项目。
5. 六款酒的效果、持续时间、档位、售价和余额可见；果汁95、酒精190为首测价格。确认后当场饮用，背包、桌面均不生成酒品；饮用不弹感受纸条。
6. 当日已喝仍能浏览；再买说限制台词，余额与效果不再变化。换夜重入、额外外出和保存重载也不能重置；翌日恢复一次。余额不足、取消、问外带都不消耗资格。
7. 第8–14天的帮忙接待，确认递酒单只完成一次，可拒绝后再帮；没有赠酒、Buff、收入或长期项目。帮忙与当天喝一杯互不排斥；第15天起不再显示。
8. 首次点击雨幕才说模拟雨的两句；再次点击不重复。磁带机首次介绍后选曲，之后直接选曲。Title与Intro至少开放，不生成磁带物品；室内音乐不盖语音，离开恢复原生音乐通道。
9. 闲聊按可用池推进，没有每天打卡或缺席惩罚；第8天不能说昨天的客人，第12天后才出现逐渐习惯的句子。
10. 第二封三语纸条的٩(ˊᗜˋ*)و及(´,,•ω•,,)♡完整可见。新台词无录音时正常打字、口型，不串播旧录音。
11. 原型旧档的35 CR杯和pickup_point保留历史，不解锁新帮助或占用当天杯数；关闭实验开关不改当铺、奖励和Buff。消费中断恢复只处理能核对的钱包/Buff快照，不重复付款；含糊记录显示酒款核对提示。

第三周：付薪夜班与次日回应（按v4.4由作者实机验收）
自动回归覆盖日历与独立限次、订单归属、工资快照恢复、A/B冻结、稳定抽签、周一合并及赠酒补投。以下主要确认真实操作与演出；开发检查不启动游戏。
1. 第14天仍是第二周免费开业帮助，第15天起改为“帮忙接待客人 · 60 CR”。从未在当铺相识也能工作，先自我介绍，工作对白不用“前辈”，不假定玩家拥有店铺。
2. 第三次实际周一见面收购食物、预算250，提出有薪邀请；此前已经打工时用已合作替换句。缺席顺延，不按日历补刷章节。
3. 第一次询问工作先出现两句邀请；第二周帮过递酒单才有一次回响。不确认或拒绝不发钱、不耗订单，可以稍后再问。
4. 确认后先正常播完开始对白，再显示吧台附近约3秒进度条，依次招呼客人、整理订单、收尾，有两声轻微杯碰；完成才一次性增加60 CR并当面感谢。进度条不挡脸，1080p/1440p/2160p均可读。
5. 途中离场或重读档不发钱；回来可重开未提交班次。完成后重进、额外外出、再次点击、保存重载均不重复发工资；次日有新需求时才可再工作。
6. 分别先喝再工作、先工作再喝，两项各一次；不互相刷新限额，不额外扣夜访次数，不绕过原生封锁或禁足。
7. 无需求的测试存档由开发参数将某日订单数设为0或不足3，工作说“今天暂时忙得过来”，不发工资；菜单刷新或重入不刷出订单。正常一班账为195销售、90材料、60工资、45增量净额。
8. 第三次会面当晚不工作、只喝酒或中断工作，次日送A和nightfall；完成并领取工资则送B和同一盘磁带，均与成交无关。两封信的中文原文不改，不增加第三种纸条。
9. 延迟第三次会面：更早打过工、会面当晚没打工仍是A；当晚完成则B。满背包补投和重读档保留已选版本，不重复送信或磁带；切换中日英时文字与手写层一致。
10. 首次已结算班次35%感谢只抽一次；使用不同测试存档分别验证中与未中。未中后再工作不重抽；中则次日额外小满在队尾，不替换原生顾客，不推进主线。
11. 额外来访先感谢并送一杯固定果汁，再可选收购食物/水，采购共100 CR，拒售也赠酒。礼物满载待补投，读档不重发、不换款；没有额外磁带、纸条或普通交易回礼。
12. 感谢顺延到周一时只出现一个小满，在正常首句后插入两句感谢；沿用当章预算和结尾，不额外增加100 CR，不多推进章节。不营业则待办继续顺延。
13. 三日效果、雨幕、选曲、闲聊、动态立绘及环境受光保持。工作后闲聊只反馈实际当日班次，不强制签到；关闭实验性酒馆后保留工作历史，不影响原有当铺剧情。

动态酒馆场景（由作者实机验收）
1. 场景现在经第8天的正式入口进入，保持原生背包、离场与气泡操作；本轮不启动债务或长期经营。
2. 雨仅出现在左侧玻璃，吊灯、顶灯与霓虹错开明暗起伏；吧台和地板反光正常观看可察觉，暗墙保持稳定。磁带机电平柱、转轮高光和局部光晕继续保留，当前为合成节奏而非真实音乐同步。连续观看至少三个5秒循环，检查接缝、黑帧、闪烁及颜色变化。
3. 小满在中央，比上一版等比缩小12.5%，保持吧台后的腰线。右侧录音机完整可见。人物、吧台前景与视频在1080p、1440p、2160p和窗口缩放中保持对齐；嘴、眼睛与原生气泡独立正常，店铺人物尺寸不受影响。
4. 进入、离开、再次进入与停用模组后不残留画面或继续播放。播放准备阶段及失败时有静态后备图；对比首次进入和再次进入的内存，不应按循环持续上涨。
5. 场景菜单只显示本周功能，旧普通杯、协作和账本不出现；只有确认饮品会扣款，其他点击不额外消耗外出机会。
6. 小满、雨幕和磁带机的透明命中区在不同分辨率下准确，气泡与菜单优先接收点击；取货架、水槽、管线不触发旧功能。三语菜单完整，新台词暂不录音。
7. 小满每4秒轻微抬起头肩再回落，最大位移约底图2.7像素；腰部始终被吧台遮住，不拉伸面部和身体。对话、眨眼、配音口型独立正常，气泡不随呼吸上下抖动。关闭人物动画后恢复静止；离开再进入、窗口缩放后不漂移。
8. 帽沿及头肩的暖灯亮部、靠窗侧冷蓝与衣服下缘的粉紫反光在正常视距下可察觉，避免只有整体变暗或整个人变紫；面部中央变化更轻、五官与原有蓝色仍清楚。染光随背景灯光而变，视频卡住或静态后备时不自行闪动；眨眼和口型切帧不能闪回无光颜色。离开、重进和停用后没有过亮或材质残留，店铺人物不受酒馆染光影响。

抬枪反应测试（只瞄准，暂不开火）
独立测试包可运行 `tools/build-gun-test.ps1` 准备；需要本机安装时添加 `-Install`。在游戏模组管理关闭主模组、开启“小满抬枪测试版（独立）”并重启。任意日期开门后等测试小满排到队尾；需要再次邀请时按 `Ctrl+Shift+M`。测试版没有交易、主线推进、赠礼、酒馆或配音，完成后关闭测试版并重新开启主模组。
1. 在小满开场说到一半、等候交易、成交回应三个时点抬枪。沿用原生枪械与视窗；按作者选定的表情显示原作担心眼神与小汗滴，阴影位于箭头指示的两侧刘海缝隙上半截，发根最浓、向眉毛渐淡，下缘比旧版更早结束。眼睛、蓝色虹膜、眉毛线条、脸型、头发和身体保持基线，不出现扩眼缩瞳、放大汗滴、拼接块或柜台穿帮。
2. 新台词仅字幕，原生打字机继续工作；嘴随出现的字符开合，省略号停顿和说完闭嘴，持续瞄准时不恢复平静脸。关闭打字机时不空嚼；关闭立绘动画时保持静态口型。
3. 左键及任何原生开火入口均不能射击小满：无枪火、伤害、尸体、追捕或存档后果；右键仍可正常收枪。其他顾客的原生持枪行为不变。
4. 收枪后显示“……吓了我一跳。”，随后续接原生暂存对话。分别测试自动推进、手动推进与跳过台词，不重复开场回调、交易或赠礼。
5. 在收枪回应尚未结束时再次抬枪，反复切换后仍能回到最初对话。等待时再次抬枪不把她直接送走。
6. 切换中日英、变更立绘大小、放大视窗、离店、读档和停用模组后，不残留惊吓状态、字符监听或额外纹理；下一位原生顾客正常。

第四周与本轮界面验收
- 宽屏和窗口模式下，小满身旁正文与选择气泡应紧凑；左下角只有背包／返回两个按钮，无常驻说明窗。隐藏与显示背包不放大气泡。
- 酒单六卡展示图片、价格、效果与购买并饮用，窄屏三列；当天喝过或资金不足不可重复购买。首三周仍可正常喝酒。
- 小满磁带机为原生播放器，可从小满盒内拖磁带到播放区，操作播放/暂停/切曲/音量；尝试拿到背包和放入玩家磁带均应拒绝。离开恢复当铺音乐状态，无新增收藏品。
- 22/23/24天各测一次电话确认，次日评估；25天拨号关闭。无库存也能登记和听评估；成交与否26天都收到未通过通知。未申请不出现评估员、公函、王哥。
- 预约次日不营业可顺延一日且不晚于25天；王哥与原版王哥撞期应延期，不替换原生台词，不新增工资或主线赠礼。
- 第4次会面前签约、当晚签约、次日才签约分别测B/B/A；第二页清单实际可读，已发旧信不重发。迟见面不重开22–24天电话窗口。
- 先交一瓶满水，只增加原料；再交一盒完整加工果汁，产生六杯，玩家2／店内4。反复进场读档不能增产；买完玩家份额不影响店内份额，现场饮用反之亦然；信用点按价表双方实付。
- 背包满则批发不扣钱不发货；重复确认、读档、拖走原料后再确认都不能重复结算。错误／脏水／半瓶水不增加产量。
- 打工感谢本周中奖后不再抽；下一周工作可重新抽，未中奖可在后续班次抽一次。未完成回礼先保留；旧存档回执与工资不丢。


第五、六周：高档酒与推荐顾客（开发分支，作者操作）

1. 第28天夜间仍是旧六款酒；第29天不论是否第五次会面，都能从商品卡酒单切到“高档酒”。首次说明只出现一次，旧酒仍能正常买；两款300 CR、有限余量，不可外带。新杯型暂复用原作已验证素材。
