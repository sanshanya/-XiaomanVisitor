# 实机验收

本页只列游戏内操作。规则和数值见[项目手册](项目手册.md)；自动测试不勾选实机结果。每轮记录安装版本、游戏版本、存档、语言／分辨率、启用的其他Mod及实际结果。

## 原生流程与主线

- [ ] 酒馆新设置默认开，已保存的关闭选择保留；修改无警告、重启生效，关后周一主线、收藏和酒效正常。
- [ ] 主线、感谢、材料、推荐与评估访客只追加队尾；原生人物、数量、顺序、电话、报纸和其他地点正常。
- [ ] NEWS仅在3–7、22–24、57、71–73天显示对应文章，过期撤下，原生四条优先；招商电话仅明确同意才预约次日评估。
- [ ] 正常／缺席周一均只推进实际见面的一章；同日读档不重复。预算、需求、曲目无0值或占位符。
- [ ] 不成交、不夜访也能在次日收到纸条与磁带；满载保留部分投递，已有收藏不搬动，读档不重发。首封只给一次信笺簿／磁带盒。
- [ ] 第三封A/B只取实际会面当夜完成的工作，第四封A/B按相应签约记录冻结；后来的选择不改旧信。
- [ ] 第5、6、12、14次赠酒种类、数量和唯一性正确，赠酒周不额外售酒；露华夜领／补投共用一份。
- [ ] 第13／14次分别检验待处理、留下、离站的口头稿与纸条；仅明确离站者撤地点，十四盘与最后三杯不重发。

## 酒馆、消费与工作

- [ ] 第1–2天无地点，3–7天仅装修预览，第8天开放；原生外出次数和限制不变。
- [ ] 右下角背包／返回及原生地面、口袋、容器可用；往返不复制物品。选项向右避开正文，点外部只收起选项。
- [ ] 酒单半透明、可拖动、Buff／期限完整；快速切普通／高档酒单、关闭重开及读档，旧按钮不能买单或切回旧页面。
- [ ] 雨幕与磁带机首次介绍不重播。播放器仅有当章一盘，可拖播放、不能带走；离店后原生音乐和物件交互恢复。
- [ ] 每日最多一杯：取消／不足额不扣钱，成交金额与效果正确，不生成外带物品；重入／读档不刷新资格。
- [ ] 当天先喝背包中的宇宙空间，再到店买同款，扣190 CR并正常完成，不报核对异常；原有酒效到期日不被额外延长。旧uncertain单当日仍拦重复付款，隔日可买；明确已扣款的中断单跨天恢复，不重复扣款、延长过期效果或覆盖后喝的同类酒。
- [ ] 六酒三天含当天，异类叠加、同类替换；特殊酒一天。露华仅提高实际卖货收入，拾荒酒不解除原生禁用，声望酒不加任务声望或损失。
- [ ] 开业递酒单可拒绝后再帮，不领工资；有薪工作完成才发工资，中断不算，工作／喝酒资格独立。感谢来访、赠酒和私人采购不重抽或重复结算。

## 材料合作

- [ ] 未签约不来，周三晚签约约下周三；周五明确续签才再预约。暂停保留已收材料履约，较新选择不被旧页面／旧周五答复覆盖。
- [ ] 正常听完、快速跳过及等气泡自动关闭，收料表都只打开一次并能提交；等待中换对白／读档不能补开旧表。更换同数量无效物品时拒收名称刷新。
- [ ] 报价显示估值、上限、预计成酒及达上限／拒收状态；合格水、原料、酵母按规则估值，其他物品拒收。未登记、无预约、处理中、已交本批均有明确原因。
- [ ] 单件／多件材料完整移走，双方现金不变；空台、撤回、取消和无效物品不安排送酒。正价值可收，上限按周增长且暂停不重置，其他原生以物易物正常。
- [ ] 250 CR材料当周五交两大瓶、留25 CR；不足小瓶只留余值，之后不重复加成。收料、部分交酒和续签前分别读档，不重扣、不重发、不丢余值。
- [ ] 新旧合作瓶身、售价与占格正确，旋转／收纳／读档保持。首次实体合作酒交付才发3×3蓝酒箱；剧情酒和仅记余值不发箱，满载后不重复补箱，准入正确。
- [ ] 十四次后仍留店者继续有效周三／周五合作；未签、暂停、未续签不自动来。固定取餐合同不替代材料协议，离站后无新预约。

## 对白、立绘与清理

- [ ] 走近、站定、讲话、离开清晰度连续，身体被前景正常遮挡；放大／持枪视窗切回正常，酒馆呼吸、眨眼、环境光和口型正常。
- [ ] 小满在场时改变显示设置，离开后保留新选择，下一位原生顾客相机恢复；抬枪／收枪不覆盖原剧情或重发礼物，其他顾客射击规则照旧。
- [ ] 中日英字幕、表情和录音逐句对应；语音停顿闭嘴，缺录音／关配音时正常打字，不借播旧句。分别启停Station Voices验证双方语音。
- [ ] 采购、感谢、隐藏回访、周五续签、收枪恢复分别听完／跳过，结束动作只生效一次；不赶走下一位顾客。通话挂断／重拨后旧答复不能申请或结束新通话。
- [ ] 白天／酒馆对白中读档、离店或停用，旧完成动作不能开表、确认合作或记入闲聊。只清理自有访客、窗口、热点、声音和等待，保留玩家物品与原生对话。
- [ ] 多次往返、切语言、开窗口后无持续残留；记录实际帧率与内存，不用素材体积推算性能。

## 经营与结局

- [ ] 账本默认隐藏；开关只改变入口／窗口，不改账或重复结算。输入未确认时切页、跨日、读同日其他存档，旧输入和按钮不能修改当前账户。
- [ ] 新档完整周起账，旧档先确认租约，不补历史收入或利息；旧离站保持。旧十期自动核账账户按剩余营业天数恢复，不补造停业收入。
- [ ] 第九次仍高光、第十次竞争、第十二次才提示账务；漏见不提前推进。看通知／账本或借款到期不自动停业，申请核账后先结本周业务，暂停后才计办理期限。
- [ ] 小满独立租约每周涨10%、逐次取整；错过会面和暂停后复业不重置，玩家买下当铺不免小满租金。旧档历史金额、已签订单和已收材料报价不重算。
- [ ] 旧900 CR周转金、已重组并留下的档升级后，用店内现金先付到期款，不为攒2000而误停业；已进入补救且现金够的档，主动申请恢复时只扣店内真实到期款，回执标明酒馆付款、重复操作不再扣。店内现金不够时保持原账，不自动扣玩家钱。
- [ ] 新帮工6单发120 CR、店内净增90；旧3单60 CR班次在读档后按原额完成。500 CR新供料周五仅入150 CR净收益，反复打开账本不重入，旧批次不补发经营收益。
- [ ] 第12次后按最近三周真实销售核算一次1,500 CR违约金；达9,000 CR免收，材料和分租不充抵。现金实际支付，未付记费用；早期帮助留存实际利润，重组也不能长期免疫上涨房租。
- [ ] 每周最多一项协作，与当晚工作互斥；中断不完成。两份合同分日签署、各次日回执；重组前不产生合同收入。展期按冻结资格逐次确认，不补过去营业或刷新资格。
- [ ] 未拥有当铺、零援助也能普通重组；实际首期订单、租金、储备与还款达成才成立留下。代偿确认一次、按实欠封顶，含糊钱包变化暂停；保证自愿有限且不改产权或期限。
- [ ] 现场酒、工作、推荐与合同收入不重复记账；清债后无新利息，酒馆和材料合作继续。十四次后决定留下／离站只补对应信，不重复磁带或酒。
- [ ] 隐藏线以两次实际特殊水成交和次日回访触发；药效20为包含边界，低于20不触发。三次拒绝及开门五幕路径各验证，字幕／配音／三次血迹同步，重选／读档后无残留。
