# XiaomanVisitor project rules

- Actual root: this repository, not DSH-Go. Read `docs/项目手册.md` first; it owns current requirements, architecture, source inputs and workflow. The current development version comes only from `package/XiaomanVisitor/manifest.xml`.
- Preserve the namespace, item IDs and saved-data keys. Append Xiaoman to the native Monday queue; never replace native story customers. Calendar days, encounter indices and future financial weeks are separate clocks.
- Tavern access is experimental and defaults off via native `experimental_tavern` config. Capture the restart-required choice on enable; keep location registration, discovery, progress initialization, scene loading and actions gated. Disabling preserves existing tavern data and does not affect Monday content.
- Week two uses the approved v4.1 source: discovery day 3, opening day 8, no day-one preview override. Keep calendar, encounter and per-day drink clocks independent. Retain prototype history; no legacy pickup flag becomes opening reception help. Onsite drinks create no items, use the existing buffs and fail closed on ambiguous payment recovery.
- Week three uses v4.4. Paid shifts start on day 15 and consume persisted source-tagged overflow orders, separately from drinks and W02 help. Freeze note A/B from the third encounter night's completed paid receipt, never from older work. Preserve both Chinese originals; no third note variant. W04 supersedes first-shift-only thanks: each paid shift may draw once, at most one win/visit per calendar week, preserving pending and legacy receipts; extra tail visitor or Monday merge; no extra story/tape progression.
- Keep pure rules in `src/Domain`, native adapters/presentation/lifecycle in `src/Runtime`, generated catalogs in `src/Generated`. Domain code may use JSON/BCL and stable identity constants; no Unity or native game side effects. Do not add a service framework or speculative finance implementation.
- Use native rendering and APIs first. Keep the verified SpriteRenderer/material/movement/foreground path; no UI portrait overlay or manual counter clipping. Scope camera changes to visible Xiaoman, keep departure ownership after native client cleanup, restore display state and respect new player settings. Shared portraits have one owner and are released after sprites/stages.
- Native portrait baseline: `baseline/native-render-0.0.3.3`. Evidence/tradeoffs: `docs/渲染问题复盘与性能取舍.md`. Camera pixel-area ratios are not FPS measurements; maximum texture size is not a VRAM budget.
- Use reviewed source inputs from the manual, not archived prose or Downloads. Keep Chinese/Japanese/English player text, original artwork and audio hashes stable unless the author requests changes. Regenerate catalogs from their inputs; do not patch generated catalogs alone.
- Runtime voice plays packaged audio only. Credentials and generation stay outside the mod. Offline checks must never call paid TTS or send messages.
- `tools/setup-dev.ps1` restores the environment. `tools/verify-dev.ps1` runs daily checks; add `-Full` for text/assets/release. Preserve meaningful regressions; remove dead tests and repeated combinations rather than chasing assertion counts. Native checks require the actual local game; do not claim them without it.
- After native API updates, scan with the installed game's scanner and reject `Pending` as well as current refusals/undeclared capabilities. Voice waits use the mod-owned `ModHelper` coroutine API; never fix a scan warning by adding a retiring capability.
- Tests/reports/build products belong under `tests` / `.dev`, not authored story files. Do not introduce per-version report copies into Git. Keep game assemblies/decompilations, saves, secrets and release archives out of Git; use LFS for media.
- `main` tracks the Workshop baseline and `v*` tags retain published releases; work on `develop/tavern`. Build/check never installs or publishes. The author handles gameplay testing; do not launch or control the game for tests unless explicitly requested. Keep the installed verified version unless installation is requested; Workshop publishing requires an explicit author request. Read existing localized Workshop metadata before updating it, use explicit languages, and update the existing item only.

- Week four uses the approved v4.6-W04 source. Keep application/world dates independent of encounter four; real supply inventory and single-allocation production batches, separate player/bar shares. Author permits configurable first-test economics. No speculative debt ledger. Native phone and tail visitors must not replace contacts, important news or native Joe Wild visits. Freeze letter four A/B from the encounter night signature, never later transactions.

- Weeks five/six use the approved v4.7 source and author-confirmed final W06 letter/rules in story/第五周实现.json and story/第六周实现.json. Preserve six original reward drinks. Luxury shares use the existing finite supply batches; no fabricated trial revenue or duplicate ingredient cost. Improvised gift is one-off, +37 luck for consumption day. Referrals use persisted daily draws, no Monday, 25%, Sunday guarantee, no weekly cap, at most one arrival/day and retained backlog; native buyer pricing and tail queue. No new paid TTS.

- Weeks seven/eight use v4.8 with the author's inline W08 hairclip-letter override (story/第八周纸条_作者修订.txt), not the attachment's superseded photo-reply letter. Keep W07 customer talk/photo letter and W08 photo talk/hairclip letter separate. Add no gameplay, items, customers or revenue. Preserve 450/500 budgets and diary/gallery1. Night chats require actual chapter encounter plus calendar floor; late encounters use neutral time wording. Japanese remains draft; no paid TTS.

- Week nine uses the final prosperous revision in story/第九周实现.json, not the superseded decline/competitor-visit draft. Day57 newspaper only discloses Polar Day; ads say 30% of normal price and 500 CR worth of drinks, never a player cash grant. Keep 450 CR/Food/lost, final ice-maker note without an added tape sentence, and a single three-line night chat. Preserve actual work/supply/referral receipts and scene; no forced decline, expansion, fake NPC revenue or tenth-week story. Japanese remains draft.
