# 小满的十四个星期一｜第三周：忙碌的夜班

> 《深空当铺 × 小满酒馆》剧情与玩法设计稿 **v4.4-W03**  
> **状态：第三周剧情整合实施稿。** 第三封纸条 A/B 中文采用作者确认文本，不作额外润色；其余中文为待实机验收稿，日语为录音前审阅稿。薪资、订单和概率均属首测参数，尚未完成经济平衡实测。  
> **范围：** 第三次周一当铺会面、夜间付薪协助、次日根据是否实际打工选择的第三封纸条及 `nightfall` 磁带、第三周其余日常，以及首班有薪工作后可能触发的额外感谢来访。  
> **不做：** 每日随机事件、可见客人立绘、复杂调酒小游戏、债务与重组、长期客源项目 L1–L4 的自动解锁。

## 0. 先冻结这周的核心决定

| 维度 | 第三周规则 |
|---|---|
| 开始时间 | **第 15 天（第三个星期一）**起开放正式夜间打工；与第三次有效周一见面、成交与收到纸条无关 |
| 白天剧情 | 小满提到船坞换班时客人集中到店，她一个人忙不过来；主动邀请前辈来帮忙，**明确会支付工资** |
| 夜间菜单 | 沿用 `酒单／互动／只是看看`；`互动` 子菜单为 `闲聊／帮忙接待客人／返回` |
| W02 与 W03 区别 | W02“递一次酒单”是无薪的开业生活事件；W03 起“帮忙接待客人”是**可重复、按次付薪的正式夜班**，两个标记和回执严格分开 |
| 打工频次 | 同一**游戏日最多完成一次班次**；重复进酒馆不刷新。此限制独立于当日一杯酒 |
| 打工与饮酒 | 同一夜访可以打工并购买、饮用一杯酒；两项分别结算，但都必须遵守各自限额 |
| 每次打工回报 | **首测 60 CR 工资**，在确认完成真实订单后支付；正式数值以后调优 |
| 酒馆收益 | 首测一班多接待 3 笔本会流失的订单：客单 65、材料 30、工资 60；每班酒馆**净增 45 CR**，玩家获得 60 CR |
| 订单来源 | 只处理当天已生成的“等候/溢出需求”，**不得把已经计入基础客流或 L1 项目的订单再记一遍** |
| 纸条与磁带 | 第三次有效会面次日必达纸条与 `track_key: nightfall`；纸条选 A/B，磁带相同。文案取决于**该次会面当晚**是否成功完成有薪打工，赠礼资格与打工无关 |
| 额外感谢来访 | **第一次完成正式付薪夜班**后仅抽签一次（首测 35%）；中奖则在次日安排一次非主线来访：当面感谢、送一杯封装的现有酒、顺便按独立限额收购货物；不触发磁带或主线推进 |
| 额外事件边界 | 若未中奖不反复重抽；后续各周的随机客人/随机事件机制不在此稿范围 |
| 后续日常 | 打工可继续作为常规选择；少量普通闲聊和工作反馈，不做每天一个新事件或签到奖励 |

**人物原则：** 小满提出请求，是因为她的店开起来了、确实需要帮手；她坚持支付工资，因为玩家也在经营当铺。不是撒娇求救，更不是提前预告第十二周的危机。她忙，但开心。

### 2.4 打工演出：短进度条，而非三张订单小游戏

2. 确认后，场景进入**短暂工作演出**：吧台附近出现进度条，目标约 **3 秒**，由 0% 走到 100%；文案可在“招呼客人 → 整理订单 → 收尾”三段中切换，配合两声轻微杯碰／提示音。无需新增客人立绘。

## 3. 双方都获益：工资和酒馆收入如何真实成立

### 3.1 首测确定性算例（每班）

| 项目 | 数值 | 账务含义 |
|---|---:|---|
| 玩家协助额外接待 | 3 单 | 当晚**本会流失**的需求，未计入基础 NPC 客流或其他经营项目 |
| 客单价 | 65 CR | 三单收入 **195 CR** |
| 单笔材料成本 | 30 CR | 三单成本 **90 CR** |
| 支付玩家工资 | 60 CR | 小满酒馆的真实支出，玩家的钱包增加 60 CR |
| **酒馆新增净经营现金** | **45 CR** | `195 − 90 − 60`，尚未含已有店租、固定费用与融资费用 |

以上三个单价沿用现有经济候选稿中的 **65 CR 客单价、30 CR 材料成本**；工资 60 CR 是本周建议的首测新参数。**正收益不是无条件凭空发放：必须先存在且履约三笔未被计入其他收入的需求。**

示例：玩家在第三周只工作两晚，酒馆新增可用经营现金 `45 × 2 = 90 CR`，玩家拿到 `60 × 2 = 120 CR`。如果天天上班，账本按真实每天订单结算，不因反复进店或重复点菜单多次发工资。后续正式需求引擎减少待接订单时，班次和收益也要随之变化。

**工程边界：** 当前 `develop/tavern` 分支还没有完整的酒馆 NPC 订单/现金流结算系统；实施时至少要写入可重放的班次订单、收入、材料、薪水和净额日志。未来接入经济 v0.3，不得再次把这些订单和工资作为新交易叠算。若没有足够需求，则不能声称酒馆必然盈利；应该隐藏本班上岗或给出“今晚不忙”的自然反馈。

### 3.2 为什么不采用“点击一次 +60 CR，小满也 +60 CR”

这种做法相当于同一个按钮无来源地创造 120 CR，与以后要上线的经营债务模型相冲突，也会让“打工”沦为每天进店签到。小满从额外接到的订单中付出材料和工资后，留下真正的经营结余，才符合双方各自开店、彼此合作的设定。

### 3.3 与长期经营 L1 的关系

- 本周付薪协助是**当天的一次性增量营业**；不会自动解锁长期稳定订单或改变项目等级 `L`。
- 后续 L1 是**改变长期接待能力／班次安排**的经营选择。若同一批船坞顾客已计入某班实际销售，**不得同时再算作 L1 的额外客流**。每单必须具有唯一 `order_id` 与收入归属。
- 是否让“连续帮工”对 L1 起到铺垫作用，可以在第三周之后单独设计。本轮不引入隐藏好感/工作次数门槛。
- 这是一份**劳动合作**，不是免费劳动力、慈善捐款或玩家入股；工资不能同时被写成玩家给小满的经营注资。

## 4. 第三次有效会面次日｜纸条与第三盘磁带

### 4.1 A/B 选择条件（P0）

- **时间：** 第三次有效周一会面发生的游戏日记为 `D`；次日 `D+1` 投递第三封纸条和第三盘磁带，绝不依赖当日是否成交。
- **A：** `D` 夜间**没有成功完成有薪打工**。包括未去酒馆、只喝酒或闲聊、选择打工但取消、进度动画中断且班次未结算。
- **B：** `D` 夜间**确实完成有薪打工，并且工资与班次记录已经成功提交**。
- **选择时点：** 不能在周一白天见面时提前决定纸条版本。等当日夜间结算结束，再以班次记录固定 `visit_03_note_variant=A|B`，将来补投也使用同一版本。
- **两版共通：** 都只投递 `story_note_03` 与 `track_key: nightfall` 各一份。磁带本身不需要每周重新设计赠送理由，第三周只轻轻提一句“这是这周的磁带”。
- **独立事件：** 首次打工后的概率感谢来访不决定 A/B，B 纸条也不保证一定发生感谢来访；二者可以同一天存在但不重复送音乐和工资。

## 5. 首次有薪打工后的概率感谢来访（新增）

### 触发与频率

- **资格：** 玩家在第三周（游戏日 ≥15）或以后**首次实际完成一班有薪工作**，班次工资和经营回执已成功持久化。

- **时机：** 中奖则安排 `工作日 D + 1` 的白天特殊来访；若当日无法接待，保留单个 pending，在下一个合法营业日安排，台词使用“上次”而非强行说“昨天”。

### 事件交互与资金结算顺序

1. 进入可接班次前，检查玩家当日未工作、酒馆正常营业、存在三单可接的额外需求；记录当前可执行班次 ID。
2. 玩家确认工作，显示简短执行动作；关闭/取消在提交前不发生任何资金变化。
3. 短进度条结束后，记录三单的 **195 CR 销售、90 CR 材料、60 CR 工资**，酒馆新增净额 45；玩家钱包实际增加 60。资金变更与完成标记以同一稳定 `shift_id` 实现幂等恢复。
4. 当天同一个 `shift_id` 在读档、UI 重开、重复回调中只能提交一次。不得把显示金额或 UI 刷新作为再次发薪信号。
5. 工作完成后仍可以饮用当日尚未购买的一杯酒；若先喝过则只能工作、闲聊或听音乐，不会因为打工而获得第二杯额度。
6. 首次有薪班次**成功提交后**，才按存档稳定结果抽一次额外感谢来访，并登记次日队列；取消上班或仅播放动画不触发。
7. 第三次有效会面日夜间结算后，以同游戏日的**已提交班次回执**冻结纸条 A/B。次日按原赠礼系统投递对应纸条和固定的第三盘磁带，失败只补投，不重新选择版本。
8. 在原生夜间外出允许条件内执行。进入酒馆已消耗一次外出机会，打工不再额外扣机会；次日原生顾客名额减少、短眠者豁免和禁足规则仍由原生处理。

**旧存档迁移：** 当前 `TavernProgress.MayAct(day)` 将旧普通杯与 `pickup_point` 互斥为每天唯一活动，不能直接沿用；改为“本日饮酒”“本日有薪工作”“W02 开业帮助”三条独立状态。保留原有历史 `cup/pickup_point`，但不能把旧 `pickup_point` 当作 W03 已经上班、也不能补发工资。

## 10. 本周叙事完成标准

第三周玩家第一次能够真正在小满的酒馆**工作**。她会高兴地承认玩家帮了自己，但也会认真支付报酬，因为她把自己的酒馆当作一份正经事业，也尊重前辈经营当铺的时间。

这份工作能让小满接住原本可能流失的订单；玩家得到薪水，她的店也留下利润。两个人之间因此多了一层关系：不仅是喜欢磁带的熟人、店主与顾客，还曾经在忙碌的夜晚一起照看过一间小店。

**第三封纸条不再替磁带编故事。** 她只需要自然地说一句“这是这周的磁带”，写信是为了回应前辈的真实处境，而不是定期交剧情周报。

**没有人需要在第三周被拯救。** 小满只是开店之后有点忙，也有点开心。她会为了一个忙碌的夜晚开心，才让后面需要真正面对困难的故事有分量。
